## 网络架构详解

### 总体参数量

| 组件 | 参数量 |
|------|--------|
| Forward Map F | 135.8M |
| Style Critic Q_D | 134.8M |
| Aux Critic Q_R | 134.8M |
| Actor π | 31.9M |
| Discriminator D | 2.9M |
| Backward Map B | 0.2M |
| **总计** | **440.5M** |

### 架构详情

| 组件 | 架构 | 激活函数 | 并行网络数 |
|------|------|---------|-----------|
| Critics (F, Q_D, Q_R) | ResNet (4嵌入块+6残差块, 2048隐层) | Mish | 2 (ensemble) |
| Actor π | ResNet (4嵌入块+6残差块, 2048隐层) | Mish | 1 |
| Discriminator D | MLP (2层, 1024隐层) | ReLU | 1 |
| Backward Map B | MLP (1层, 256隐层) | ReLU | 1 |

### 残差块设计

Critics和Actor使用类Transformer的残差块：
- 残差连接
- Layer Normalization
- Mish激活函数
- 嵌入：4个残差块，2048隐层
- 主干：6个残差块，2048隐层

### 输入输出

| 组件 | 输入 | 输出 |
|------|------|------|
| F | (o_{t,H}, s_t, a_t, z) | d维后继特征 |
| Q_D | (o_{t,H}, s_t, a_t, z) | 1维Q值 |
| Q_R | (o_{t,H}, s_t, a_t, z) | 1维Q值 |
| π | (o_{t,H}, z) | 29维关节目标 |
| D | (s_t, o_t, z) | 1维判别概率 |
| B | (s_t, o_t) | d维潜在向量 |

## 运动初始化

### 混合初始化

每个episode的初始状态从两个来源采样：
1. **随机跌倒位置**（概率0.3）
2. **运动数据集M中的状态**（概率0.7）

### 运动优先级

基于Earth Mover's Distance (EMD)的指数优先级：

```
p(m) ∝ 2^{max{0.5; min{EMD(m), 2}} · 4}
```

每 N_eval 步重新评估所有运动并更新优先级。40条LAFAN1运动分割为10秒片段以获得更细粒度的优先级。

## 扩展性实验

### 模型配置

| 架构 | 配置 | 总参数量 |
|------|------|---------|
| ResNet | 3块, 1024维 | 60.2M |
| ResNet | 6块, 1024维 | 120.1M |
| ResNet | 3块, 2048维 | 201.1M |
| **ResNet** | **6块, 2048维** | **440.5M** (主论文) |
| ResNet | 9块, 2048维 | 679.9M |
| MLP | 2层, 1024维 | 40.1M |
| MLP | 4层, 2048维 | 179.9M |

### 关键发现

- ResNet架构优于MLP
- 更大模型几乎总是更好
- MLP在大规模时不稳定
- 数据混合（LAFAN1+AMASS）进一步提升性能
