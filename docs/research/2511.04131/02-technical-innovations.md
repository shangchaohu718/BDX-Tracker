# BFM-Zero 技术创新点

## 创新点总览

BFM-Zero的核心创新在于将**无监督RL的FB表示框架**首次成功应用于真实人形机器人，并解决了sim-to-real迁移中的一系列挑战。

---

## 1. 首个面向真实人形机器人的无监督RL

### 突破点

| 维度 | 之前 | BFM-Zero |
|------|------|----------|
| 应用场景 | 虚拟角色动画 | 真实机器人部署 |
| 训练范式 | 在线策略PPO | 离线策略无监督RL |
| 任务范围 | 单一跟踪任务 | 多任务零样本推理 |
| 实机部署 | 无 | Unitree G1成功 |

### 关键挑战

1. **离线策略训练 vs 高并行仿真**：传统方法用PPO在线策略训练，BFM-Zero需要适配大规模并行环境
2. **Sim-to-real差距**：无监督RL无显式跟踪奖励，如何确保行为可迁移？
3. **部分可观测性**：策略只有本体感受信息，如何在无监督框架下处理？

### 解决方案

通过四大设计选择（非对称训练、大规模并行、域随机化、奖励正则化）将FB-CPR从虚拟角色迁移到真实机器人。

**意义**：首次证明离线策略无监督RL是真实人形机器人控制的可行方案。

---

## 2. 可提示(Promptable)的策略设计

### 核心理念

借鉴LLM的"提示"概念，通过不同的潜在向量z来提示策略执行不同任务：

```
π(o_{t,H}, z_track) → 跟踪参考运动
π(o_{t,H}, z_goal)  → 到达目标姿态
π(o_{t,H}, z_reward) → 优化给定奖励
```

### 与传统方法对比

| 传统方法 | BFM-Zero |
|---------|----------|
| 每个任务训练一个策略 | 单一策略，不同提示 |
| 部署时切换模型 | 切换潜在向量z |
| 无法组合技能 | 线性组合z即可组合技能 |

### 奖励组合示例

```
z_combined = z_{raisearm} + z_{move_backward} → 后退同时举起手臂
```

无需额外训练即可产生新行为。

**意义**：统一接口消除任务间壁垒，支持零成本技能组合。

## 3. 结构化潜在空间

### FB表示的潜在空间特性

1. **平滑性**：语义相似的运动在潜在空间中接近
2. **可解释性**：t-SNE可视化显示按运动风格聚类
3. **可插值性**：球面线性插值(SLERP)生成语义有意义的中间行为

### 零样本插值

```
z_{t=0.5} = SLERP(z_0, z_1, 0.5)
→ 产生语义有意义的中间技能
→ 无需任何额外训练
```

### 潜在空间组织

- 跟踪轨迹在2D投影中呈带状分布
- 不同任务类型（跟踪/奖励/目标）在3D空间中有结构化分布
- 语义相似的运动自然聚类

**意义**：结构化潜在空间使策略具备零样本泛化和技能插值能力。

## 4. 自然鲁棒性与恢复能力

### 非传统的鲁棒性来源

传统方法通过大量扰动训练获得鲁棒性，BFM-Zero的鲁棒性有更深层来源：

1. **TD-based离线策略训练**：策略见过更丰富的状态分布
2. **GAN判别器**：显式鼓励类人行为，使策略拥有丰富的技能库
3. **正则化项**：约束行为在安全范围内

### 恢复行为示例

被大力推后：
1. 本能性收拢双臂
2. 快速跑步姿势后退
3. 逐渐减速
4. 重新打开双臂恢复

**关键**：即使输入是静态T-pose的单一潜在向量z，策略仍能自主偏离参考姿态、采用动态恢复姿势、最终回到原始跟踪——就像人类一样。

### 对比

| 方法 | 恢复方式 |
|------|---------|
| PPO+扰动训练 | 剧烈反应式恢复 |
| RGMT跌倒恢复 | 集成恢复策略 |
| **BFM-Zero** | **自然人类式恢复（从技能库中提取）** |

## 5. 非对称历史条件化训练

### 问题

无监督RL中，策略和Critic使用不同信息：
- 策略：仅有本体感受历史 o_{t,H}
- Critic：特权信息 (o_{t,H}, s_t)

这种非对称性在FB框架中尤为复杂，因为奖励空间是通过B隐式学习的。

### 解决方案

使用历史窗口 H=4：
- 策略输入：93·H + 64 = 436维
- 历史缩窄Actor和Critic之间的信息差距
- 提高域随机化下的适应性

### 性能影响

| 配置 | 跟踪MPJPE | 奖励 | 姿态MPJPE |
|------|-----------|------|-----------|
| 特权信息(不可部署) | 1.0749 | 299.3 | 1.0291 |
| 历史条件化(可部署) | 1.1015 | 221.9 | 1.1387 |
| 差距 | +2.47% | -25.86% | +10.65% |

性能下降有限，特别是跟踪任务。奖励任务下降较大，与奖励函数的稀疏性和推断过程的随机性有关。

## 6. 高效少样本适应

### 设计思路

零样本推理可能不完美，特别是在动力学偏移下。BFM-Zero提供两种适应方式：

### 单姿态适应

- **算法**：Cross-Entropy Method (CEM)
- **优化空间**：潜在向量 z（256维）
- **迭代次数**：20次
- **无需微调网络参数**
- **效果**：4Kg负载下单脚站立从5秒内崩溃提升到15秒+稳定

### 轨迹适应

- **算法**：双退火轨迹优化（DIAL-MPC风格）
- **优化空间**：潜在提示序列 z_{t:t+H-1}
- **效果**：跟踪误差降低29.1%
- **保留**：判别器赋予的类人先验

### 关键优势

传统微调需要修改网络参数，BFM-Zero仅在潜在空间中优化：
- 更安全（不改变网络权重）
- 更快（20次迭代vs数轮训练）
- 保留人类先验（判别器正则化）
