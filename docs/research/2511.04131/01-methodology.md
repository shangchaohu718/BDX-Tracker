# BFM-Zero 方法论

## 方法论概览

BFM-Zero框架包含三个阶段：

1. **无监督预训练** — 学习统一潜在表示和可提示策略
2. **零样本推理** — 通过不同方式提示策略执行任务
3. **少样本适应** — 在潜在空间中优化以改进性能

---

## 1. 问题建模

### POMDP定义

将真实人形控制建模为部分可观测MDP (POMDP)：

**元组**：(S, O, A, P, γ)

| 组件 | 定义 | 维度 |
|------|------|------|
| 特权状态 s | 根高度、身体姿态、旋转、线/角速度 | 463维 |
| 观测 o | 关节位置(归一化)、关节速度、根角速度、重力向量 | 64维 |
| 动作 a | 29个关节PD控制器目标 | 29维 |
| 历史观测 o_{t,H} | H步本体感受+动作 | 93·H + 64维 |

**运动数据集** M = {τ}，包含无标签运动轨迹（观测+特权状态）。

---

## 2. Forward-Backward表示

### 2.1 核心思想

FB框架学习长期策略动力学的有限秩近似：
- **Backward映射 B: S → R^d**：捕获低频特征，总结状态间的长期时序依赖
- **Forward映射 F: S × A × Z → R^d**：策略条件化的后继特征

关键分解：
```
M^{π_z}(ds'|s,a) ≈ F(s,a,z)^T · B(s') · ρ(ds')
```

### 1.2 潜在任务空间

Backward映射 B 诱导出一族线性奖励函数：
```
r_z(s) = φ(s)^T · z
```

每个潜在向量 z 对应一个策略 π_z，优化该线性奖励。z ∈ Z (d维超球面) 定义了任务中心化的潜在空间。

**关键**：奖励函数是**学习得到**而非给定的，因此可以表示广泛的任务。

### 2.3 训练损失

**FB损失**（时序差分）：
```
L(F,B) = E[(F(x,a,z)^T · B(x⁺) - γ·F̄(x',a',z)^T · B̄(x⁺))²]
       - 2·E[F(x,a,z)^T · B(x')]
```

## 3. BFM-Zero预训练

### 3.1 四大关键设计

**A) 非对称训练**：
- 策略(Actor)：仅使用观测历史 o_{t,H}
- Critic：访问特权信息 (o_{t,H}, s_t)
- 历史缩窄Actor和Critic之间的信息差距

**B) 大规模并行环境**：
- 受FastTD3启发
- 数千并行环境 + 大回放缓冲区 + 高UTD比率
- 使离线无监督训练具有可行性和稳定性

**C) 域随机化**：
- 物理参数随机化（质量、摩擦、关节偏移、质心）
- 扰动随机化（随机推力）
- 传感器噪声注入
- 防止过拟合仿真动力学

**D) 奖励正则化**：
- 辅助Critic Q_R 学习安全约束
- 惩罚项：关节极限、脚部滑动、动作变化率、自碰撞等

### 3.2 三个Critic

| Critic | 输入 | 目的 |
|--------|------|------|
| FB (F·z) | 历史观测+特权+动作+z | 后继特征 / Q值估计 |
| Discriminator Q_D | 历史观测+特权+动作+z | 风格正则化（类人行为） |
| Auxiliary Q_R | 历史观测+特权+动作+z | 安全和物理可行性约束 |

### 3.3 判别器训练

GAN风格目标，使用变分Jensen-Shannon散度：

```
L(D) = -E_{τ~M}[log(D(o,s,z_τ))] - E_{(o,s,z)~D}[log(1-D(o,s,z))]
```

其中 z_τ = (1/l(τ)) · Σ B(o,s) 是运动的零样本模仿嵌入。

判别器奖励：r_d = D/(1-D)

### 3.4 最终Actor损失

```
L(π) = -E[F(x,a,z)^T · z + λ_D·Q_D(x,a,z) + λ_R·Q_R(x,a,z)]
```

三项组合：
1. **FB项**：策略优化（后继特征方向）
2. **判别器项**：行为像人类（λ_D=0.05）
3. **辅助项**：安全约束（λ_R=0.02）

## 4. 零样本推理

### 4.1 奖励优化

给定任意奖励函数 r(s)，潜在向量：
```
z_r = (1/N) · Σ r(s_i) · B(s_i)，其中 s_i ∈ D
```

使用在线回放缓冲区的子采样估计。

### 4.2 目标到达

给定目标状态 s_g：
```
z_g = B(s_g)
```

策略自然过渡到目标姿态并保持，无需显式插值。

### 4.3 运动跟踪

给定运动序列 τ = {s_1,...,s_n}，使用前瞻horizon：
```
z_t = Σ_{t'=t}^{t+H} B(s_{t'})
```

策略序列逐步跟踪参考运动。

## 5. 少样本适应

### 5.1 单姿态适应 (CEM)

1. 从零样本潜在 z^init = B(s_g, o_g) 开始
2. 使用Cross-Entropy Method (CEM)优化
3. 20次迭代
4. 目标：J(z) = Σ(r_task(s_t) - α_R·Σr_k(o_t,s_t,a_t))

**应用**：单脚站立+4Kg负载

### 5.2 轨迹适应 (双退火优化)

1. 从跟踪运动序列热启动
2. 对潜在提示序列 z_{t:t+H-1} 执行零阶采样优化
3. 使用DIAL-MPC风格的双退火调度
4. 粒子数N=2048，温度β₁=0.85, β₂=0.9，迭代M=6

**应用**：跳跃运动（地面摩擦变化），误差降低29.1%

