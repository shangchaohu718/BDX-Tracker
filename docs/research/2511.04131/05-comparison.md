## 与SONIC对比

| 维度 | SONIC | BFM-Zero |
|------|-------|----------|
| 核心 | 规模扩展 | 无监督学习 |
| 训练数据 | 700+小时 (100M+帧) | LAFAN1 (40条运动) |
| 训练资源 | 128 GPU × 3天 | 单GPU级别 |
| 模型参数 | 42M (单一策略) | 440.5M (全部组件) |
| 训练方式 | PPO(在线策略) | FB-CPR(离线策略无监督) |
| 任务指定 | 编码器切换 | **潜在向量提示** |
| 命令接口 | 编码器(机器人/人类/混合) | Backward映射B(统一) |
| 多任务 | 多编码器+共享解码器 | **单策略多提示** |
| 技能组合 | 规划器级别 | **潜在空间线性组合** |
| 跨体态 | 隐式重定向 | 无专门处理 |
| 多模态控制 | 文本/视频/音乐 | **奖励函数(等价于语言提示)** |
| VLA集成 | GR00T N1.5 | 无 |
| 开源 | 否 | 待定 |

### 核心差异

**SONIC**：通过大规模数据和计算获得通用跟踪能力，用编码器实现多模态输入
**BFM-Zero**：通过无监督RL获得结构化潜在空间，用潜在向量实现多任务推理

两者代表不同路径：SONIC是"扩展"路线，BFM-Zero是"表示学习"路线。

## 总结

### BFM-Zero的核心定位

BFM-Zero是**首个在真实人形机器人上证明无监督RL可行**的工作：

**独特优势**：
1. 多任务零样本推理（跟踪/目标/奖励）
2. 结构化可解释潜在空间
3. 技能插值和组合能力
4. 自然鲁棒性和恢复能力
5. 少样本适应能力

**关键代价**：
1. 模型复杂度高（440.5M参数，多组件）
2. 数据需求看似小但依赖质量
3. 缺乏专用遥操作和视觉接口
4. 量化结果缺乏与SOTA的直接比较
5. 训练稳定性可能不如PPO

**最佳使用场景**：作为**行为基础模型**，为上层应用提供多功能的底层控制能力，特别是需要多任务切换和技能组合的场景。
