# BFM-Zero 实验结果

## 实验概览

BFM-Zero在Unitree G1 (29-DoF) 和 Booster T1 上进行全面评估：

1. **仿真验证** — 非对称训练影响、域随机化效果、sim-to-sim、OOD泛化
2. **实机部署** — 跟踪、目标到达、奖励优化、扰动恢复
3. **少样本适应** — 单姿态适应、轨迹适应
4. **潜在空间分析** — 可视化、插值、语义结构
5. **扩展性实验** — 数据规模、模型规模

---

## 1. 仿真验证

### 1.1 非对称训练与域随机化

| 配置 | 测试环境 | 测试数据 | 跟踪 | 奖励 | 姿态 |
|------|---------|---------|------|------|------|
| BFM-Zero-priv | Isaac (无DR) | LAFAN1 | 1.0749 | 299.3 | 1.0291 |
| **BFM-Zero** | **Isaac (DR)** | **LAFAN1** | **1.1015** | **221.9** | **1.1387** |
| BFM-Zero | MuJoCo (DR) | LAFAN1 | 1.0789 | 207.3 | 1.1041 |
| BFM-Zero | MuJoCo (DR) | AMASS | 1.0342 | - | 1.4735 |

**分析**：
- BFM-Zero相比特权版本：跟踪退化2.47%，奖励退化25.86%，姿态退化10.65%
- 跟踪性能下降很小，证明非对称训练有效
- 奖励退化较大，与稀疏奖励函数和推断随机性有关
- 域随机化后的策略在MuJoCo中表现良好（sim-to-sim差距<7%）

### 1.2 奖励推断的稳定性

- `move-ego-0.3`：性能分布一致，推断稳定
- `move-ego-0.0`：少数实例性能很差
- 原因：域随机化增加了训练数据的随机性，小样本推断更脆弱

### 1.3 Sim-to-sim

- Isaac → MuJoCo：所有变化<7%
- 域随机化和历史组件共同贡献鲁棒性

### 1.4 OOD泛化

- 175条AMASS运动（CMU子集）+ 10个AMASS姿态
- 在MuJoCo中测试（结合动力学差异+OOD任务）
- **成功泛化到未见运动和姿态**

## 2. 实机部署

> **所有实机结果来自同一个模型**

### 2.1 运动跟踪

| 能力 | 说明 |
|------|------|
| 风格化行走 | 多种行走风格 |
| 高动态舞蹈 | 高度动态的舞蹈动作 |
| 格斗和体育 | 拳击、运动动作 |
| 低质量视频运动 | 视频重定向的次优运动，仍能跟踪 |
| 跌倒恢复 | 不稳定或跌倒时自然恢复并继续跟踪 |

**关键发现**：
- 对低质量运动数据具有鲁棒性（单目视频遮挡、估计伪影）
- 跌倒恢复行为自然且安全——不是通过大量扰动训练获得的鲁棒性，而是通过丰富的技能库

### 2.2 目标到达

- 随机采样目标姿态（去除速度分量）
- 零样本潜在 z_g = B(s_g)
- 连续到达不同目标姿态，无需显式插值
- 轨迹平滑自然
- 即使目标不可行也能收敛到近似姿态

### 2.3 奖励优化

三大任务族：
1. **运动奖励**：基座速度+角速度命令
2. **手臂运动奖励**：手腕高度命令
3. **骨盆高度奖励**：坐下、蹲下、低姿态移动

**关键能力**：
- 简单奖励定义即可精确执行
- 线性组合奖励 → 技能组合（如后退+举臂）
- 单一奖励可产生多种行为模式（取top-k潜在向量的均值）
- 对人类用户直观，适合语言提示

### 2.4 扰动恢复

| 扰动类型 | 恢复行为 |
|---------|---------|
| 踢腿部 | 保持稳定 |
| 强力推 | 一个平滑后退步 |
| 拖倒 | 自然站起来回到T-pose |
| 大力前推 | 收臂→跑步姿态→减速→恢复 |

**超越传统鲁棒性**：不是被动抵抗扰动，而是自主适应。即使输入静态T-pose的z，策略也能自动偏离参考、采用动态恢复姿态、最终返回——如同人类。

## 3. 少样本适应

### 3.1 单姿态适应

**场景**：单脚站立 + 4Kg负载（模拟质量偏移）

| 配置 | 结果 |
|------|------|
| 零样本 z^init | 5秒内崩溃（环境碰撞） |
| CEM优化 z* (20次迭代) | 15秒+稳定单脚站立 |

**附加奖励**：右脚离地>15cm且无意外接触

**意义**：仅通过潜在向量优化即可补偿负载引起的动力学偏移，无需微调网络参数。

### 3.2 轨迹适应

**场景**：跳跃运动（地面摩擦变化）

| 配置 | 结果 |
|------|------|
| 零样本跟踪 | 基线误差 |
| 轨迹优化后 | 误差降低29.1% |

**优化参数**：N=2048粒子，β₁=0.85, β₂=0.9, M=6迭代

## 4. 潜在空间分析

### 4.1 可视化

- **2D t-SNE**：跟踪轨迹呈带状分段，按运动风格聚类
- **3D t-SNE**：跟踪/奖励/目标到达的潜在向量有结构化分布

### 4.2 插值

使用球面线性插值(SLERP)在两个潜在向量间生成中间行为：

```
z_{t=0.5} = SLERP(z_0, z_1, 0.5)
```

- 中间行为**语义有意义**
- 在仿真和实机上均有效
- **零样本**，无需额外训练
- 证明潜在空间的平滑性和结构化

### 4.3 技能组合

通过线性组合奖励潜在向量实现技能组合：
- 后退 + 举臂 → 同时执行的复合技能
- 行走 + 旋转 → 自然转弯

## 5. 扩展性实验

### 5.1 数据规模

| 数据 | 说明 |
|------|------|
| LAFAN1 | 40条运动 |
| AMASS (CMU+BMLHandball) | 更多运动 |
| 混合 | LAFAN1 + AMASS不同比例 |

**发现**：
- 增加数据量普遍改善跟踪性能
- LAFAN1单独使用时性能较早饱和
- 混合数据（含LAFAN1）对奖励推断尤其重要

### 5.2 模型规模

| 架构 | 参数量 | 跟踪趋势 |
|------|--------|---------|
| MLP 2层 1024 | 40.1M | 基线 |
| MLP 4层 2048 | 179.9M | 改善 |
| ResNet 3块 1024 | 60.2M | 改善 |
| ResNet 6块 2048 | 440.5M | **最优** |
| ResNet 9块 2048 | 679.9M | 继续改善 |

**发现**：
- ResNet一致优于MLP
- 更大模型几乎总是更好
- MLP在大规模时训练不稳定
- 跟踪性能随模型容量单调改善

### 5.3 奖励推断数据源

| 数据源 | 效果 |
|--------|------|
| 运动数据集 | 更好的奖励性能 |
| 在线回放缓冲区 | 性能下降明显 |
| 混合 | 中等 |

**原因**：缓冲区样本经过域随机化，运动数据集则没有。

## 6. Booster T1 适配

- 相同超参数
- LAFAN1通过LocoMujoco重定向到T1
- 成功实现自然行走和富有表现力的舞蹈
- 验证框架的跨机器人泛化能力

---

## 实验总结

### 核心发现

1. **无监督RL可成功部署到真实人形机器人**
2. **单一模型零样本执行多种任务**（跟踪/目标/奖励）
3. **自然且安全的恢复能力**超越传统方法
4. **少样本适应有效**（29.1%误差降低）
5. **潜在空间结构化**，支持零样本插值和技能组合
6. **扩展趋势积极**：更大模型+更多数据→更好性能

### 局限

- 定量结果仅给出MPJPE值，未与其他方法直接比较
- 奖励推断在域随机化下可能不稳定
- 仅用LAFAN1（40条运动）训练，数据规模有限
